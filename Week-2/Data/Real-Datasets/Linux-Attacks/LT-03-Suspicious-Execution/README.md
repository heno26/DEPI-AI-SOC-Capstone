# LT-03 — Suspicious Execution

Linux suspicious process execution investigation dataset.

## Overview
This dataset supports the investigation of suspicious process execution activities using Sysmon event logs.

## Dataset Contents
- LT-03-Sysmon-original.txt — Original Sysmon logs.
- LT-03-focused.json — Focused security events.
- LT-03-Case-Study.md — Investigation case study.
- LT-03-evidence-mapping.csv — Evidence mapping.
- LT-03-Verified-Timeline.csv — Verified event timeline.
- LT-03-Source-Manifest.json — Source metadata.
- LT-03-Selection-Manifest.json — Event selection details.
- LT-03-Final-Verification-Manifest.json — Final verification records.

## Purpose
- Analyze suspicious process execution.
- Identify potentially malicious commands and activities.
- Correlate security events.
- Validate evidence and event timelines.
- Support AI-assisted SOC triage and incident investigation.
