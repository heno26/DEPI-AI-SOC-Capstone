# Linux Attack Datasets

This directory contains Linux security datasets used in the DEPI-P5 AI-Assisted SOC Automation and Incident Response Capstone.

## Attack Scenarios

| ID | Scenario | Description |
|---|---|---|
| LT-01 | SSH Brute Force | Analysis of SSH authentication attacks and repeated login attempts. |
| LT-02 | Privilege Escalation | Investigation of suspicious privilege escalation activities. |
| LT-03 | Suspicious Execution | Detection and analysis of potentially malicious Linux command execution. |

## Purpose

These datasets support:

- Security event analysis.
- AI-assisted SOC alert triage.
- Threat detection and classification.
- Evidence-based incident investigation.
- SOC report generation.

## Dataset Organization

Each scenario is stored in a separate directory to preserve its original evidence and associated testing files.
