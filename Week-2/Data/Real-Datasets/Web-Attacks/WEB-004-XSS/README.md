WEB-004 — Cross-Site Scripting (XSS)

The dataset is intended for security monitoring, evidence-based SOC investigations, AI-assisted threat classification, timeline reconstruction, and analyst validation workflows within the DEPI-P5 AI-Assisted SOC Automation & Incident Response Capstone.
