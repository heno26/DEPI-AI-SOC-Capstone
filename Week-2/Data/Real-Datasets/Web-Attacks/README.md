
Web Attacks Datasets
Overview
This directory contains web security datasets used in the DEPI-P5 AI-Assisted SOC Automation & Incident Response Capstone.

The datasets in this section focus on web-based attack scenarios and related investigation workflows. They are intended to support security log analysis, evidence collection, incident reconstruction, threat classification, and SOC analyst validation activities.

Dataset Purpose
The Web-Attacks collection is used to:

Investigate suspicious web application activity.
Analyze web server and application logs.
Support evidence-based incident response workflows.
Evaluate AI-assisted security analysis pipelines.
Reconstruct attack timelines and analyst findings.
Validate investigation results through human review.
