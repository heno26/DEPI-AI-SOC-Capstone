# win2022-evtx

## Overview

This directory contains selected Windows Event Log channels extracted from a Windows Server 2022 dataset and preserved for baseline analysis, validation, and SOC training purposes.

The collection provides representative Windows event sources commonly used during security monitoring, event correlation, forensic review, and AI-assisted SOC workflows.

## File Inventory

| File Name | Type | Purpose |
|------------|--------|---------|
| Application.evtx* | Windows Event Log | Application-related events generated by applications and services running on the system. |
| Microsoft-Windows-Sysmon%4Operational.evtx* | Windows Event Log | Sysmon operational events used for process, network, and system activity monitoring. |
| Security.evtx* | Windows Event Log | Windows Security log containing authentication, authorization, and audit events. |
| System.evtx* | Windows Event Log | Windows operating system events related to services, drivers, and system operations. |

\* File extensions are inferred from the visible Event Log file type.

## Investigation Objectives

This dataset supports:

- Baseline Windows activity analysis.
- Windows Event Log familiarization.
- Event correlation exercises.
- Security monitoring validation.
- False-positive assessment.
- AI-assisted classification testing.
- Human analyst review and training.

## Evidence Integrity

The event log channels are preserved as collected and retained in their original format whenever possible.

Maintaining the original event log structure supports reproducibility, traceability, and validation throughout SOC investigation workflows.

## AI-Assisted SOC Integration

This dataset can be used for:

- Baseline behavior profiling
- Event classification testing
- Security log analysis
- False-positive reduction
- Investigation validation
- SOC reporting workflows

AI-generated findings should always be reviewed and validated by human analysts before operational use.
