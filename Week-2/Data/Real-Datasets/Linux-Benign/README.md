# Linux Benign Datasets

This directory contains legitimate Linux system activity datasets used in the DEPI-P5 AI-Assisted SOC Automation project.

## Test Scenarios

| ID | Scenario | Description |
|---|---|---|
| LT-04 | Normal Operations | Analysis of legitimate Linux administrative and system activities. |

## Purpose

- Validate AI-assisted benign activity classification.
- Reduce false positives in SOC investigations.
- Distinguish authorized administrative operations from suspicious behavior.
- Support evidence-based SOC triage.
