Windows Attacks Datasets
Overview
This directory contains Windows-based attack datasets used in the DEPI-P5 AI-Assisted SOC Automation & Incident Response Capstone.

The datasets focus on common adversarial techniques observed in Windows environments and are intended to support SOC investigations, security event analysis, incident reconstruction, AI-assisted threat classification, and analyst validation workflows.

Dataset Collection

Evidence Integrity
All datasets are maintained to preserve traceability between original evidence and derived investigation artifacts.

Evidence mapping, documentation, and verification files help maintain consistency and support reproducible security investigations.

These datasets are intended to support:

Security event analysis
Threat classification
Incident timeline reconstruction
False-positive assessment
SOC report generation
Human analyst review and validation
AI-generated conclusions should always be reviewed by analysts before operational use.
