# LT-04 — Normal Operations

Linux benign activity dataset for SOC analysis and false-positive validation.

## Overview
This dataset contains legitimate Linux system and administrative activities used to evaluate AI-assisted SOC triage.

## Dataset Contents

- LT-04-Linux-original.txt — Original Linux logs.
- LT-04-focused.txt — Selected benign events.
- LT-04-Case-Study.md — Investigation case study.
- LT-04-evidence-mapping.csv — Evidence mapping.
- LT-04-Verified-Timeline.csv — Verified event timeline.
- LT-04-Source-Manifest.json — Original source metadata.
- LT-04-Selection-Manifest.json — Event selection records.
- LT-04-Final-Verification-Manifest.json — Final verification results.

## Purpose

- Identify legitimate Linux administrative activities.
- Validate benign event classification.
- Reduce false-positive SOC alerts.
- Verify evidence and event timelines.
- Evaluate AI-assisted security analysis accuracy.
