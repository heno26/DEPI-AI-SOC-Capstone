# Network Attack Datasets

Network security datasets used in the DEPI-P5 AI-Assisted SOC Automation and Incident Response Capstone.

## Attack Scenarios

| ID | Scenario | Description |
|---|---|---|
| NT-01 | Port Scanning | Detection and investigation of suspicious network reconnaissance and port scanning activity. |
| NT-02 | DNS Anomaly | Analysis of unusual DNS queries and potentially suspicious DNS behavior. |
| NT-03 | C2 Beaconing | Investigation of potential command-and-control communication patterns. |

## Dataset Structure

Each scenario contains original network evidence, selected events, verification records, and supporting investigation documentation.

## Purpose

- Network threat detection.
- Evidence-based SOC investigation.
- AI-assisted security event classification.
- False-positive reduction.
- Incident timeline reconstruction.
