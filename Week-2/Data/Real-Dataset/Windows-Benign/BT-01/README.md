# BT-01 — Windows Benign Activity

## Overview

This dataset contains benign Windows activity collected for baseline security analysis and validation purposes.

The dataset is intended to support SOC analyst training, false-positive assessment, event correlation exercises, AI-assisted classification testing, and comparison against attack-oriented investigation datasets.

## Investigation Objectives

This dataset supports:

- Baseline Windows activity analysis.
- False-positive assessment.
- Security event validation.
- Event correlation exercises.
- AI-assisted activity classification.
- Human analyst review and verification.
- SOC workflow testing.

## Evidence Integrity

The dataset includes supporting traceability artifacts to preserve relationships between source material and derived investigation datasets.

Evidence mapping and source manifests help maintain consistency, transparency, and reproducibility throughout analysis activities.

## AI-Assisted SOC Integration

This dataset can be used for:

- Baseline behavior analysis
- Event classification testing
- False-positive reduction workflows
- Investigation validation
- SOC reporting exercises
- Human analyst review

AI-generated assessments should always be validated by human analysts before operational use.
