# BT-02 — Windows Benign Activity

## Overview

This dataset contains benign Windows activity collected for baseline monitoring, validation, and SOC training purposes.

The dataset is intended to support normal activity profiling, false-positive assessment, AI-assisted classification testing, event correlation exercises, and human analyst validation workflows within the DEPI-P5 AI-Assisted SOC Automation & Incident Response Capstone.
